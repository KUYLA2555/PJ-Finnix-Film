# FINNIX FILM — เว็บไซต์ Brand & Corporate

เว็บไซต์แบรนด์ของ **บริษัท ฟินนิกซ์ ฟิล์ม จำกัด** (ฟิล์มกรองแสงรถยนต์)
static site ล้วน — ไม่มี build system ไม่มี package manager หนึ่งหน้า = หนึ่งไฟล์ HTML ที่มี CSS และ JS อยู่ในไฟล์เดียวกัน

> **repo ส่วนตัว ยังไม่พร้อมขึ้นเซิร์ฟเวอร์จริง**
> มีค่าที่ยังไม่ยืนยัน (`{{VAR}}` 40 กว่าตัว) · เงื่อนไขรับประกันยังเป็นโครงร่าง · ส่วน "ผลงาน" ในหน้าแรกยังเป็นข้อมูลสมมติ
> รายการที่ต้องปิดก่อนขึ้นจริงอยู่ท้าย `docs/CHANGELOG.md` หัวข้อ "ค้างอยู่ — ต้องทำต่อ"

## เปิดดู

```powershell
python -m http.server 8000     # แล้วเปิด http://localhost:8000/
```

เปิดด้วย `file://` ก็ได้ แต่ควรใช้ local server เวลาทดสอบ motion ที่ผูกกับ scroll
ต้องตรวจสองความกว้างเสมอ — **1440px และ 375px**

## หน้าที่มี

| ไฟล์ | หน้า |
|---|---|
| `index.html` | หน้าแรก |
| `about.html` | เกี่ยวกับเรา |
| `technology.html` | เทคโนโลยี — เป็นที่อยู่ของ signature ชิ้นเดียวของเว็บ |
| `products.html` | ผลิตภัณฑ์ 5 ซีรีส์ 15 รหัส |
| `warranty.html` | การรับประกัน |
| `faq.html` | คำถามที่พบบ่อย |
| `contact.html` | ติดต่อเรา |
| `review.html` | **หน้าตรวจงานภายใน `noindex,nofollow` — ห้ามขึ้นเซิร์ฟเวอร์จริง** |

ยังขาด `/products/[series]` `/gallery` `/news` ตามข้อ 8 ของบรีฟ

## เอกสาร

| ไฟล์ | บทบาท |
|---|---|
| `CLAUDE.md` | คู่มือสำหรับ Claude Code — กฎที่ละเมิดแล้วงานไม่ผ่าน · โครงสร้างโค้ดที่ใช้ซ้ำทุกหน้า **อ่านก่อนแก้อะไรก็ตาม** |
| `docs/master-prompt.md` | บรีฟหลัก v1.0 เป็นข้อผูกมัด · อ้างอิงเป็น "ข้อ 1–12" |
| `docs/CHANGELOG.md` | บันทึกการตัดสินใจทุกเวอร์ชัน + รายการที่ยังค้าง + ตัวแปรที่ต้องขอจากลูกค้า |
| `docs/film-data.md` | ค่าสเปกจริงทั้ง 15 รหัส ถอดจากโบรชัวร์ |
| `Data/films.json` | ข้อมูลชุดเดียวกันแบบเครื่องอ่านได้ — **เป็น source of truth ของตัวเลขทุกตัวบนเว็บ** |
| `Data/*/` | สแกนโบรชัวร์ต้นฉบับ 17 หน้า |

**แก้ตัวเลขต้องแก้ที่ `Data/films.json` ก่อน แล้วค่อยลงหน้าเว็บ ไม่ใช่แก้ที่ HTML ตรงๆ**
