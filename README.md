# FINNIX FILM — เว็บไซต์ Brand & Corporate

เว็บไซต์แบรนด์ของ **บริษัท ฟินนิกซ์ ฟิล์ม จำกัด** (ฟิล์มกรองแสงรถยนต์)
static site ล้วน — ไม่มี build system ไม่มี package manager หนึ่งหน้า = หนึ่งไฟล์ HTML ที่มี CSS และ JS อยู่ในไฟล์เดียวกัน

> **repo ส่วนตัว ยังไม่พร้อมขึ้นเซิร์ฟเวอร์จริง**
> มีค่าที่ยังไม่ยืนยัน (`{{VAR}}` 25 ชนิด 38 จุดบนหน้าจริง) · รายชื่อตัวแทนกับรายการผลงานยังเป็นข้อมูลสมมติ · หน้า `/about` มี 2 ใน 5 ส่วนที่ยังเป็นบล็อกแจ้ง ไม่ใช่เนื้อหา
> รายการที่ต้องปิดก่อนขึ้นจริงอยู่ท้าย `docs/CHANGELOG.md` หัวข้อ "ค้างอยู่ — ต้องทำต่อ"

## เปิดดู

```powershell
python -m http.server 8000     # แล้วเปิด http://localhost:8000/
```

เปิดด้วย `file://` ก็ได้ แต่ควรใช้ local server เวลาทดสอบ motion ที่ผูกกับ scroll
ต้องตรวจสองความกว้างเสมอ — **1440px และ 375px**

## โครงสร้างโฟลเดอร์

```
PJ_Finnix_Film/
├── *.html          7 หน้าจริง — หนึ่งหน้าจบในไฟล์เดียว ห้ามแยก CSS/JS ออก (ข้อ 9)
├── tools/          sync-shared.py — ทำให้ "ของร่วม" ทุกหน้าตรงกัน (ไม่ใช่ build system)
├── assets/         ภาพที่เว็บเรียกใช้ + ภาพอ้างอิงภายใน + Brochure/ (PDF 5 ซีรีส์)
├── data/           films.json — source of truth ของตัวเลขทุกตัว
├── scans/          สแกนโบรชัวร์ 17 หน้า แยกตามซีรีส์ (ถอดเป็นข้อความครบแล้ว)
└── docs/           บรีฟ · CHANGELOG · film-data · review.html (หน้าตรวจงานภายใน)
```

ทุกโฟลเดอร์มี `README.md` ของตัวเองอธิบายว่าข้างในคืออะไรและมีกฎอะไร

## หน้าที่มี

| ไฟล์ | หน้า |
|---|---|
| `index.html` | หน้าแรก |
| `about.html` | เกี่ยวกับเรา |
| `technology.html` | เทคโนโลยี — เป็นที่อยู่ของ signature ชิ้นเดียวของเว็บ |
| `gallery.html` | ผลงานของเรา — แท็บ 2 ประเภทงาน + กริดการ์ด 20 คันติดป้าย "ตัวอย่างการแสดงผล" รอ `{{PORTFOLIO_ITEMS}}` |
| `centers.html` | **หาศูนย์ติดตั้ง (ใหม่ v3.4)** — แผนที่ + รายชื่อตัวแทน กรองตามจังหวัดหรือใกล้ฉัน · เป็นปลายทางของ CTA ทั้งเว็บ |
| `faq.html` | คำถามที่พบบ่อย |
| `contact.html` | ติดต่อเรา |
| `docs/review.html` | **หน้าตรวจงานภายใน `noindex,nofollow` — ห้ามขึ้นเซิร์ฟเวอร์จริง** |

**v2.6 ตัด `/products` กับ `/warranty` ออกจากเว็บตามคำสั่งผู้สั่งงาน** — IA ที่ใช้จริงจึงเป็น เทคโนโลยี · ผลงาน · ตัวแทน ไม่ใช่ 3 แกนของบรีฟข้อ 8 · ทั้งสองไฟล์ยังกู้จาก git ได้
**v3.4 แยกตัวค้นหาตัวแทนออกจาก `/contact` ไปเป็น `/centers`** — หน้าติดต่อเหลือหน้าที่เดียวคือบอกช่องทางติดต่อ และ CTA ทั้งเว็บเลิกชี้ออกไปโดเมนภายนอกแล้ว

## เอกสาร

| ไฟล์ | บทบาท |
|---|---|
| `tools/README.md` | วิธีใช้ `sync-shared.py` กับข้อควรระวัง — **อ่านก่อนแก้ของร่วม (tokens · nav · drawer · footer)** |
| `CLAUDE.md` | คู่มือสำหรับ Claude Code — กฎที่ละเมิดแล้วงานไม่ผ่าน · โครงสร้างโค้ดที่ใช้ซ้ำทุกหน้า **อ่านก่อนแก้อะไรก็ตาม** |
| `docs/master-prompt.md` | บรีฟหลัก v1.0 เป็นข้อผูกมัด · อ้างอิงเป็น "ข้อ 1–12" |
| `docs/CHANGELOG.md` | บันทึกการตัดสินใจทุกเวอร์ชัน + รายการที่ยังค้าง + ตัวแปรที่ต้องขอจากลูกค้า |
| `docs/film-data.md` | ค่าสเปกจริงทั้ง 15 รหัส ถอดจากโบรชัวร์ |
| `data/films.json` | ข้อมูลชุดเดียวกันแบบเครื่องอ่านได้ — **เป็น source of truth ของตัวเลขทุกตัวบนเว็บ** |
| `scans/*/` | สแกนโบรชัวร์ต้นฉบับ 17 หน้า |

**แก้ตัวเลขต้องแก้ที่ `data/films.json` ก่อน แล้วค่อยลงหน้าเว็บ ไม่ใช่แก้ที่ HTML ตรงๆ**
