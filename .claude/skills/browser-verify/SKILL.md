# ตรวจงานด้วยเบราว์เซอร์อัตโนมัติ — ย้ายมาจาก CLAUDE.md (3 ต.ค. 2569 · /doctor · v10.0 ย้ายวิธีตรวจที่เหลือมาด้วย)

## ข้อจำกัดของเครื่องนี้

**ตรวจงานด้วยเบราว์เซอร์อัตโนมัติในเครื่องนี้ไม่น่าเชื่อถือ — `requestAnimationFrame` ไม่เดินเลย**
วัดแล้วพบว่า rAF loop เปล่าๆ ที่ไม่เกี่ยวกับ CSS ของหน้า วนไม่ครบ 1 วินาทีใน 45 วินาที = **เฟรมเรตแทบเป็นศูนย์ในแท็บที่ถูกสั่งงานอัตโนมัติ**
ผลที่ตามมาคือ **ตัวนับ `.cnt` ค้างกลางทาง** (เห็น `0.3 / 0.6` แทนที่จะจบที่ `3 / 7`) และ **สั่ง screenshot ผ่าน CDP ค้างครบ 30 วินาที** — ทั้งสองอย่างเป็นอาการของสาเหตุเดียวกัน **ไม่ใช่บั๊กของโค้ดตัวนับ**
การฉีด `backdrop-filter:none` ช่วยให้แคปหน้าจอผ่านได้บ่อยขึ้น จึงควรทำก่อนตรวจเสมอ **แต่ไม่ได้แก้เรื่อง rAF** — v1.8 เคยสรุปว่า `.filtered` ใน hero เป็นตัวการ **ซึ่งพิสูจน์แล้วว่าไม่ใช่**
**ตัวนับกับ motion ที่ผูกกับ scroll ต้องเปิดดูด้วยตาในเบราว์เซอร์จริงเท่านั้น อย่าตัดสินจากผลอัตโนมัติ**

**หน้าต่างเบราว์เซอร์ในเครื่องนี้ย่อต่ำกว่า ~500px ไม่ได้ — แต่ `<iframe>` วัดแทนได้ (v3.1)**
สร้าง iframe กว้างตามต้องการชี้ไปหน้าเดียวกัน iframe มี viewport ของตัวเอง media query ข้างในจึงคำนวณตามความกว้างนั้นจริง และเป็น same-origin จึงอ่าน `getComputedStyle` / `getBoundingClientRect` ข้ามเข้าไปได้ · **ใช้ยืนยันจำนวนคอลัมน์ · ความกว้างช่อง · การล้นแนวนอน ที่ 375px ได้จริง ไม่ใช่การจำลอง** · ภาพแคปมือถือก็ใส่ iframe กว้าง 375 ในหน้าห่อแล้วแคปหน้าห่อ (แคปตรงที่ 375 เชื่อไม่ได้)
**อีกสองอย่างที่ยังพังในแท็บอัตโนมัติ นอกจาก rAF** — **transition/animation ค้างที่ค่าเริ่มต้น** ต้องฉีด `*,*::before,*::after{transition:none!important;animation:none!important}` ก่อนอ่าน computed style ถึงได้ค่าปลายทางจริง (ไม่ครอบ pseudo-element แล้วมันค้างค่าเริ่มต้น) · **`MediaQueryList` `change` ไม่ยิงเลย แม้แต่ listener ที่วางเองสดๆ** — ทดสอบสาขาที่ผูกกับเบรกพอยต์ด้วยการ**โหลด iframe ใหม่ที่ความกว้างเป้าหมาย**แทน
**Chrome headless แคช CSS ข้ามรอบ** — วัดซ้ำหลังแก้ CSS ต้องใช้ `--user-data-dir` ใหม่ หรือให้ server ส่ง `Cache-Control: no-store`
**อย่ารัน Chrome headless สองตัวพร้อมกันกับ server ทดสอบตัวเดียว** — v8.7 ได้หน้าไม่มี CSS (วัดผิดเป็นล้นจอ) รันทีละตัวแล้วปกติ
**`win.scrollTo` ใน iframe ต้องใส่ `behavior: 'instant'`** — `style.css` ตั้ง `scroll-behavior: smooth` ซึ่งต้องใช้เฟรม เลื่อนไม่ไปเลย (`scrollY` ค้าง 0)
**แผนที่ Google ทำให้ iframe ไม่ยิง `load`** — สคริปต์ทดสอบต้องมี timeout สำรอง (แผนที่ทุกจุดโหลดเมื่อกดเปิด/ค้นหาเท่านั้น)
**Git Bash แปลงอาร์กิวเมนต์ที่ขึ้นต้นด้วย `/` เป็นพาธ Windows** (`/PJ-Finnix-Film` → `C:/Program Files/Git/PJ-Finnix-Film`) — ใส่ `MSYS_NO_PATHCONV=1` หน้าคำสั่ง Chrome

## วิธีที่ใช้ได้

**server ทดสอบ** — Python `http.server` ที่เสิร์ฟโปรเจกต์ และ map `/__t/` ไป scratchpad (ไฟล์ทดสอบไม่ต้องวางในโปรเจกต์ · origin เดียวกันจึงอ่าน DOM ใน iframe ได้ และ CSP `'self'` ยอมสคริปต์ทดสอบ) + ส่ง `Cache-Control: no-store`
หน้าทดสอบใน `/__t/` โหลดแต่ละหน้าใน `<iframe>` ตามความกว้าง แล้วเขียนผลลง `<pre>` → รัน `chrome --headless=new --user-data-dir=<ใหม่> --virtual-time-budget=120000 --dump-dom http://127.0.0.1:<port>/__t/check.html` แล้วอ่าน `<pre>` จาก DOM ที่ได้
ภาพแคป: `--screenshot=<ไฟล์> --window-size=1440,1500` กับหน้าห่อที่ใส่ iframe แล้วเลื่อนไปจุดที่ต้องการ

**ชุดตรวจประจำ** (11 หน้า × 1440 และ 375 · เพิ่ม 1050 / 760 เมื่อแก้ layout)
- **ล้นแนวนอน** — `documentElement.scrollWidth` เทียบ `clientWidth`
- **ตัวหนังสือไทย <12px · คอนทราสต์ <4.5** — ไล่ทุก element ที่มี text node ภาษาไทย อ่าน `getComputedStyle` (ข้ามข้อความที่ทับรูป)
- **การ์ดเหลือใบเดียวในแถวสุดท้าย** — นับ `getBoundingClientRect().top` ของลูกใน grid
- **header ชนกัน** — เทียบกล่องโลโก้ / เมนู / ปุ่ม
- **JS error** — Chrome `--enable-logging=stderr --v=0` แล้ว grep `CONSOLE|Uncaught` · **ใส่หน้าที่มี error จริงเป็นตัวเทียบเสมอ** (ได้ 0 บรรทัดโดยไม่มีตัวเทียบ = ยังไม่รู้ว่าจับได้จริง)
- **ลิงก์ · anchor · id ซ้ำ** — สคริปต์ Python อ่านทุกหน้า: ทุก `href`/`src` ภายในต้องมีไฟล์ · `#ส่วน` ต้องมี id ในหน้าปลายทาง · id ในหน้าเดียวกันห้ามซ้ำ (สำคัญเมื่อแก้บล็อกร่วมที่ใส่ทุกหน้า)
- **path ย่อยเหมือนเว็บจริง** — server ที่ map `/PJ-Finnix-Film/` ไปโปรเจกต์และคืน 404 ทุกอย่างนอกนั้น แล้วไล่ขอทุก `href`/`src` (จับลิงก์ที่ขึ้นต้นด้วย `/` ซึ่ง `python -m http.server` ที่ root จับไม่ได้)
- **"ลายนิ้วมือ"** (ตำแหน่ง + computed style ของทุก element แล้ว hash) — ยืนยันว่าการจัดรูปแบบโค้ดไม่เปลี่ยนผลบนจอ (เทียบก่อน/หลัง)

**ทดสอบการทำงาน** — กดปุ่ม / พิมพ์ / `requestSubmit()` ใน iframe แล้วอ่าน DOM · ลูกเล่นตอนเลื่อนถึงตรวจอัตโนมัติไม่ได้ (เฟรมไม่เดิน → IntersectionObserver ไม่ยิง) ให้ใส่ `.playing` เองแล้วเทียบก่อน/หลัง · **ของที่ต้องพิสูจน์ว่าเริ่มเมื่อเลื่อนถึงจริง** (รถ 3D) ให้ server ใส่ `<script src="/__t/io-shim.js">` หลัง `<head>` — IntersectionObserver ตัวแทนที่เช็คตำแหน่งด้วย `setInterval` (เวลาเสมือนเดิน)

**ที่ยังต้องเปิดดูด้วยตาคนเท่านั้น** — ตัวนับ `.cnt` · ความสวยงามจริงที่ 375px · การกด/ลากด้วยนิ้ว (ค้างข้อ 9 ใน CHANGELOG) · เวลารายงานให้เขียนว่าวัดอะไรไปแล้วบ้าง อย่าเหมารวมว่าผ่าน
