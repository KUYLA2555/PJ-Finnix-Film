### การตัดสินใจที่ต้องบันทึกไว้

**โลโก้มีสองสถานะ ไม่ใช่ไฟล์เดียวใช้ทุกที่**
ตัวอักษร FINNIX ในโลโก้เป็นสีดำสนิท (0,0,0) บนพื้นโปร่งใส ถ้าวางบนพื้น `--void` จะจมหายทั้งคำ
จึงใช้ `filter: brightness(0) invert(1)` ทำเป็นโลโก้ขาวล้วนบนพื้นมืด และใช้สีจริงเมื่อ nav เปลี่ยนเป็นพื้นขาว
ทำด้วย CSS จากไฟล์เดียว ไม่ต้องสร้างไฟล์ที่สองให้ต้องมาดูแลสองชุด

**ผลพลอยได้** — โลโก้ขาวล้วนไม่มีสีแดง ทำให้หน้าจอ hero ซึ่งเป็นพื้นมืดไม่ได้แดงเพิ่มจากการใส่โลโก้

### บั๊กที่เจอและแก้ระหว่างทาง

**โลโก้ขาวบนพื้นขาว — เจอตอนทดสอบสลับสถานะ nav**
เดิมเขียน `.nav .brand img{filter:brightness(0) invert(1);transition:filter .5s}` คู่กับ `.nav.solid .brand img{filter:none}`
ทดสอบแล้วพบว่า **ค่า filter ค้างอยู่ที่ขาวไม่ยอมเปลี่ยน** เมื่อสลับ class ทำให้โลโก้ขาวไปอยู่บนพื้นขาวจนมองไม่เห็น
ไล่หาสาเหตุด้วยการปิด transition แล้วทดสอบใหม่ พบว่าเมื่อไม่มี transition ค่าเปลี่ยนถูกต้องทันที — ต้นตอคือเบราว์เซอร์ interpolate filter list ข้ามสถานะไม่ได้ ลองเปลี่ยนเป็นค่า identity `brightness(1) invert(0)` แล้วก็ยังค้างเหมือนเดิม
**แก้โดยถอด transition บน filter ออก** การสลับทันทีมองไม่ออกอยู่แล้วเพราะ nav เปลี่ยนสีพื้นหลังพร้อมกัน
ทดสอบซ้ำทั้งสองไฟล์แล้วผ่าน — พื้นมืดได้ `brightness(0) invert(1)` · พื้นขาวได้ `none`

โลโก้สีจริงมีนกแดงและคำว่า FILM สีแดง เมื่อ nav เป็นพื้นขาว **จะเพิ่มจุดแดงในหน้าจอนั้นอีกหนึ่งจุด**

**ทางเลือกถ้าต้องการนับเคร่งครัด** — ใช้โลโก้ขาวดำทุกสถานะ โดยเปลี่ยน `.nav.solid .brand img` เป็น `filter:grayscale(1)` ซึ่งแก้ได้ในบรรทัดเดียว

#### หมายเหตุเรื่องสีแดง — เกณฑ์ข้อ 4

เปิดดูจริงในเบราว์เซอร์แล้วพบว่าแดงเกิน 2 จุด 2 หน้าจอ **แก้แล้วทั้งคู่**

- **หน้าจอ hero** เดิมมี 3 จุด — ปุ่ม nav + จุด eyebrow + เส้นบางสีแดงในภาพชั้นฟิล์มที่ขอบล่าง → เปลี่ยนเส้นนั้นเป็นสีขาวโปร่ง
- **หน้าจอสเปกตรัม** เดิมมี 5 จุด — ปุ่ม nav + จุด eyebrow + ป้าย `{{ตัวแปร}}` อีก 3 ป้ายที่ใช้กรอบและพื้นสีแดง → เปลี่ยนป้ายตัวแปรทั้งหมดเป็นสีเทากลาง

**เงื่อนไขที่เหลือ** — หน้าจอ signature มีแดง 3 จุดถ้านับแยก คือ ปุ่ม nav + ชั้นเซรามิกในไดอะแกรม + สี่เหลี่ยมสีของ Ceramic Layer ในรายการข้างเคียง
ตีความว่าสี่เหลี่ยมสีในรายการกับชั้นในไดอะแกรมคือ**สิ่งเดียวกัน** เพราะรายการทำหน้าที่เป็นคำอธิบายสีของไดอะแกรม ถ้าเปลี่ยนสีในรายการให้ต่างจากไดอะแกรม การเชื่อมโยงจะขาด
แจ้งไว้ให้ตัดสินใจ — ถ้าต้องการนับแบบเคร่งครัด ทางแก้คือถอดสี่เหลี่ยมสีออกจากรายการทั้งหมด

| nav + footer | `gap:34px` · `padding:6px` · `padding:12px 22px` · `padding:7px` · `margin:20px` | คัดลอกจาก `finnix-homepage.html` ทั้งชุดเพื่อให้สองหน้าต่อกันสนิท ถ้าแก้เฉพาะหน้านี้ nav จะขยับไม่เท่ากันเวลาสลับหน้า **ควรแก้พร้อมกันทั้งสองไฟล์เป็นงานแยก** |

## วิธีบันทึกครั้งต่อไป

เพิ่มหัวข้อใหม่ไว้บนสุด ใต้บรรทัดคั่น โดยระบุ

- หมายเลขเวอร์ชันและวันที่
- **เพิ่ม / แก้ไข / ลบ** อะไรบ้าง ระบุชื่อไฟล์เสมอ
- **การตัดสินใจที่ต้องบันทึกไว้** — เฉพาะข้อที่ต่างจากบรีฟ หรือที่คนอ่านทีหลังจะสงสัยว่าทำไมถึงทำแบบนั้น
- **ตรวจตามเกณฑ์รับงาน ข้อ 11** ทั้ง 9 ข้อ
- อัปเดตหัวข้อ "ค้างอยู่" และ "ตัวแปรที่ต้องขอ" ให้ตรงกับความจริงเสมอ
