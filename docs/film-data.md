## 1 · สิ่งที่พบใน `Data/`

หนึ่งโฟลเดอร์ = หนึ่งซีรีส์ แต่ละซีรีส์มี 3 รหัสฟิล์มเสมอ รวม **5 ซีรีส์ · 15 รหัส**

| โฟลเดอร์ | ซีรีส์ | ชื่อไทย | รหัส | หน้าเอกสาร |
|---|---|---|---|---|
| `Data/CM/` | CERAMIC | ฟินนิกซ์ เซรามิค ฟิล์ม | CM35 · CM15 · CM05 | 4 หน้า |
| `Data/TIT/` | TITANIUM | ฟินนิกซ์ ไทเทเนี่ยม ฟิล์ม | SY40 · SY20 · SY10 | 4 หน้า |
| `Data/CT/` | CRYSTALIZE | ฟินนิกซ์ คริสตัลไลซ์ ฟิล์ม | CT70 · CT40 · CT20 | 3 หน้า |
| `Data/EX/` | EXTRA CLEAR | ฟินนิกซ์ เอ็กซ์ตร้า เคลียร์ | XT35 · XT15 · XT05 | 3 หน้า |
| `Data/UV_g/` | UV GUARD | ฟินนิกซ์ ยูวีการ์ด เซรามิค | SM35 · SM15 · SM05 | 3 หน้า |

**ชื่อโฟลเดอร์กับรหัสฟิล์มไม่ตรงกัน 3 ซีรีส์** — `TIT` ใช้รหัส `SY` · `EX` ใช้รหัส `XT` · `UV_g` ใช้รหัส `SM`
ตัวเลขท้ายรหัสคือค่าแสงส่องผ่าน ยกเว้น SY ที่ตัวเลขไม่ตรงกับค่าจริงเป๊ะ (SY40 = 40% ตรง · SY20 = 20% ตรง · SY10 = 10% ตรง — จริงๆ ตรงทั้งหมด)

## 2 · ปมชื่อสินค้า — คลี่ได้แล้ว

บรีฟข้อ 1 ระบุว่าเฟสนี้มี 3 ซีรีส์คือ **XT / CM / CL** ซึ่งไม่ใช่คนละชุดชื่อกับของจริงอย่างที่บันทึกไว้ใน CHANGELOG v1.2 แต่เป็น **การเรียกด้วยรหัสฟิล์มแทนชื่อซีรีส์**

| ในบรีฟ | ของจริง | สถานะ |
|---|---|---|
| XT | `XT35/15/05` = **EXTRA CLEAR** | ตรง |
| CM | `CM35/15/05` = **CERAMIC** | ตรง |
| CL | ไม่มีรหัส CL ในเอกสารใดเลย | **ไม่ตรง** — ใกล้เคียงที่สุดคือ `CT` (CRYSTALIZE) |
| — | `SY` = **TITANIUM** | บรีฟไม่ได้พูดถึง |
| — | `SM` = **UV GUARD** | บรีฟไม่ได้พูดถึง |

โบรชัวร์ทุกเล่มเขียนตรงกันว่า *"จนได้มาเป็น 3 รุ่นหลัก"* แต่ตัวเอกสารมี 5 ซีรีส์ **ข้อความในโบรชัวร์เองก็ขัดกับจำนวนสินค้าที่มีอยู่**

**ต้องถามลูกค้า 3 ข้อ**
1. `CL` ในบรีฟหมายถึง CRYSTALIZE (CT) ใช่หรือไม่ หรือเป็นซีรีส์ที่เลิกทำแล้ว
2. เฟสนี้จะขึ้นเว็บ 3 ซีรีส์ตามบรีฟ หรือ 5 ซีรีส์ตามของที่ขายจริง
3. ถ้า 3 — TITANIUM ซึ่งเป็นตัวที่กันความร้อนได้สูงสุดในไลน์ จะถูกตัดออกจริงหรือ

## 4 · โครงสร้างข้อมูลที่เสนอ

**สองระดับ** — ซีรีส์คือหน่วยของการเล่าเรื่องและราคา · รหัสฟิล์มคือหน่วยของค่าที่วัดได้

```
series (5)  ─┬─ ตัวตน: ชื่อ · คำโปรย · เทคโนโลยี · สีประจำซีรีส์ · ภาพ
             ├─ ราคา: ผูกกับซีรีส์ ไม่ใช่รหัสฟิล์ม (ทุกรหัสในซีรีส์ราคาเท่ากัน)
             └─ variants (3) ── ค่าที่วัดได้ 6 ค่าต่อรหัส
```

ไฟล์ข้อมูลอยู่ที่ **`Data/films.json`** — ไม่ใช้ชื่อโฟลเดอร์ `data/` เพราะ Windows มองว่าเป็นโฟลเดอร์เดียวกับ `Data/` ที่มีอยู่แล้ว

ไฟล์นี้เป็น **แหล่งข้อมูลตั้งต้น ไม่ใช่ไฟล์ที่หน้าเว็บ fetch ตอนรัน** — ข้อ 9 ของบรีฟบังคับว่าหนึ่งหน้าต้องจบในไฟล์เดียว เวลาทำหน้า `/products` ให้ฝังค่าลงใน HTML โดยตรงและใช้ JSON นี้เป็นต้นทางที่ตรวจย้อนได้

### ชื่อฟิลด์

| ฟิลด์ | ความหมายบนโบรชัวร์ | หน่วย | หมายเหตุ |
|---|---|---|---|
| `code` | รหัสฟิล์ม | — | เช่น `CM35` |
| `darkness` | ความเข้ม | % | ไม่มีใน SY ทั้งชุดและ CT70 |
| `heatReject` | ลดความร้อนจากแสงแดดโดยรวม | % | **ตรงกับนิยามของ TSER** แต่โบรชัวร์ไม่ได้เขียนคำนี้ — ดูข้อ 6 |
| `vlt` | แสงส่องผ่าน | % | Visible Light Transmission |
| `reflect` | สะท้อนแสง | % | Visible Light Reflectance |
| `uv` | ป้องกันรังสี UV | % | |
| `ir` | ป้องกันรังสี IR | % | |

### แกนจัดหมวดหมู่ที่ใช้ได้จริง

ทั้งสามแกนสร้างจากค่าที่มีจริง ไม่ต้องเพิ่มข้อมูลใหม่ ใช้เป็นตัวกรองในหน้า `/products` ได้ทันที

1. **ตามความเข้ม** — 40% / 60% / 80% ทุกซีรีส์ใช้ระดับเดียวกัน (ยกเว้น CT70 กับ SY ที่เอกสารไม่ได้ระบุ) เทียบข้ามซีรีส์ที่ความเข้มเท่ากันได้ตรงๆ
2. **ตามการกันความร้อน** — 52–96% ห่างกัน 44 จุด กว้างพอที่จะแบ่งเป็น 3 ชั้นได้จริง
3. **ตามงบ** — UV GUARD → CERAMIC → TITANIUM ราคารอบคันต่างกันเกือบ 4 เท่า (8,600 → 40,600)

## 5 · ข้อค้นพบที่เอาไปเป็นเนื้อหาได้ทันที

**ข้อมูลชุดนี้พิสูจน์จุดยืนแบรนด์ได้ด้วยตัวเลขของบริษัทเอง** — ไม่ต้องอ้างค่าเฉลี่ยอุตสาหกรรมหรือแบรนด์อื่นเลย ซึ่งตรงกับข้อ 3 ของบรีฟที่ห้ามอ้างตัวเลขคนอื่น

**1 · ฟิล์มที่ใสกว่า กันร้อนได้มากกว่าฟิล์มที่เกือบทึบ**
`CM35` แสงส่องผ่าน **30%** ลดความร้อนรวม **80%**
`XT05` แสงส่องผ่าน **5%** ลดความร้อนรวม **67%**
ฟิล์มที่มืดกว่า 6 เท่า กันความร้อนได้น้อยกว่า 13 จุด — นี่คือหลักฐานตรงตัวของประโยค "ฟิล์มเข้มขึ้น ไม่ได้แปลว่าเย็นขึ้น"

**2 · ความเข้มเท่ากัน ผลต่างกันได้ถึง 23 จุด**
ที่ความเข้ม 40% เท่ากัน — `CT40` ลดความร้อน **75%** · `XT35` **61%** · `SM35` **52%**
ผู้ซื้อที่เลือกฟิล์มจากความเข้มอย่างเดียว จะได้ผลต่างกันเกินหนึ่งในห้าโดยไม่รู้ตัว

**3 · IR สูงไม่ได้แปลว่ากันร้อนดี**
`XT05` กัน IR **98%** แต่ลดความร้อนรวมได้ **67%**
`SY10` กัน IR **98%** เท่ากัน แต่ลดความร้อนรวมได้ **96%**
ค่า IR เท่ากันเป๊ะ ผลต่างกัน 29 จุด — เพราะ IR เป็นแค่ส่วนหนึ่งของพลังงานทั้งหมด อธิบายได้ตรงกับส่วนที่ 2 ของหน้า `/technology` ที่แบ่งสเปกตรัมเป็น UV / แสงที่ตามองเห็น / อินฟราเรด

**ทั้งสามข้อใช้แทนตัวเลื่อน `{{TSER_AT_VLT}}` ในหน้า `/technology` ได้เลย** — จากเดิมที่ตัวเลื่อนพิสูจน์ด้วยความยาวแถบเพราะไม่มีค่าจริง ตอนนี้เปลี่ยนเป็นเทียบรหัสฟิล์มจริงคู่กันได้
