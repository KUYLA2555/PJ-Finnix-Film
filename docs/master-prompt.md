## 2 · Anti-brief — สิ่งที่ทำแล้วถือว่างานล้มเหลว

อ่านหัวข้อนี้ก่อนหัวข้ออื่นเสมอ ถ้างานที่ทำออกมามีข้อใดข้อหนึ่ง ให้รื้อทำใหม่

1. **ห้ามใส่ animation ทุกที่** — ทุก effect ที่ใส่ต้องตอบได้ว่าช่วยให้เข้าใจอะไรขึ้น ถ้าตอบว่า "ให้ดูแพง" คือคำตอบที่ผิด
2. **ห้ามใช้ hero แบบ "ตัวเลขใหญ่ + ป้ายเล็ก + gradient"** — เป็นคำตอบสำเร็จรูปของ AI
3. **ห้ามใช้พื้นครีม (#F4F1EA) คู่ serif + accent สีดินเผา** และ **ห้ามใช้พื้นดำ + accent เขียวนีออน** — สองอันนี้คือลายเซ็นของงาน AI
4. **ห้ามใส่เลข 01 / 02 / 03 กำกับ ถ้าเนื้อหาไม่ได้เป็นลำดับจริง** — ใช้ได้เฉพาะ timeline และขั้นตอนเคลม
5. **ห้ามแต่งตัวเลขสเปก** ทุกค่าที่ยังไม่มีข้อมูลจริงต้องเขียนเป็น `{{TSER_XT}}` และรวมไว้ท้ายงานเป็นรายการที่ต้องขอจากลูกค้า
6. **ห้ามใช้ฟอนต์ที่ไม่มีชุดภาษาไทย** — Inter, Satoshi, Geist, Neue Haas, General Sans ใช้ไม่ได้ เพราะจะ fallback แล้วพัง
7. **ห้ามพูดว่า "พรีเมียม" "ล้ำสมัย" "ที่สุด" ในเนื้อหาบนเว็บ** — แสดงให้เห็น อย่าบอก
8. **ห้ามใส่ CTA เกิน 1 แบบต่อหน้า** — ปุ่มแดงมีได้ปุ่มเดียวในหนึ่งหน้าจอ
9. **ห้าม copy โครงประโยคหรือ layout ของ 3M / Solar Gard** — เสี่ยงลิขสิทธิ์และทำให้แบรนด์ดูตาม
10. **ห้ามใช้ localStorage / sessionStorage** ในไฟล์ที่ส่งให้ตรวจในแชท

## 3 · จุดยืนแบรนด์ (ใช้เป็นแกนของทุก copy)

**ความจริงที่แบรนด์ยืนอยู่บนนั้น**
> ฟิล์มเข้มขึ้น ไม่ได้แปลว่าเย็นขึ้น — ความมืดคือการลดแสงที่ตามองเห็น ส่วนความร้อนอยู่ในคลื่นอินฟราเรดที่มองไม่เห็น

นี่คือความเชื่อผิดที่คนไทยมีมากที่สุดเรื่องฟิล์ม การพูดความจริงข้อนี้ตรงๆ ทำให้ Finnix อยู่ในตำแหน่ง "แบรนด์ที่รู้จริง" ทันที ทุกหน้าควรสะท้อนตำแหน่งนี้

**น้ำเสียง**
- พูดแบบช่างที่เก่งอธิบายให้ลูกค้าฟัง ไม่ใช่แบบฝ่ายการตลาด
- ประโยคสั้น ตรง ไม่มีคำฟุ่มเฟือย
- ใช้ตัวเลขและหน่วยจริงเสมอ ไม่ใช้คำว่า "มาก" "สูงสุด" ลอยๆ
- ยอมรับข้อจำกัดได้ ความตรงไปตรงมาสร้างความเชื่อใจมากกว่าการเลี่ยง
- ห้ามใช้คำทับศัพท์ที่มีคำไทยดีอยู่แล้ว แต่คงศัพท์เทคนิคจริงไว้ (TSER, IRR, VLT, UV)

**สิ่งที่ห้ามอ้างในเนื้อหา**
- ห้ามอ้างว่าป้องกันมะเร็งผิวหนัง
- ห้ามอ้างตัวเลขของแบรนด์อื่นหรือค่าเฉลี่ยอุตสาหกรรมโดยไม่ระบุแหล่ง
- ตัวเลขทุกตัวต้องระบุได้ว่าวัดด้วยมาตรฐานใด

## 4 · Design Tokens (ค่าที่ต้องใช้ตรงตัว)

### สี
```

--ink         #0C0C0C   ตัวหนังสือหลัก
--paper       #FFFFFF   พื้นหลังหลัก
--smoke       #F4F4F3   พื้นหลังรอง สลับ section
--line        #E3E3E1   เส้นคั่น
--mute        #75756F   ตัวหนังสือรอง
--red         #CC1B1B   accent เดียวของทั้งเว็บ
--red-hot     #E82323   สถานะ hover เท่านั้น
```

**กติกาของสีแดง** ใช้ได้เฉพาะ 4 กรณี — ปุ่มหลัก, จุดกำกับ eyebrow, ชั้นเซรามิกในไดอะแกรม, สถานะ focus/error
ห้ามใช้แดงเป็นพื้นหลังใหญ่ ห้ามใช้แดงกับตัวหนังสือขนาดยาว ห้ามมีแดงเกิน 2 จุดในหนึ่งหน้าจอ

### ตัวอักษร
```

Body / เนื้อหา        IBM Plex Sans Thai 300–500   line-height 1.7–1.75
```
ห้ามใช้เกินสองตระกูล ไม่ต้องหาฟอนต์ mono มาใช้ — ป้ายเทคนิคใช้ body ขนาด 11px + letter-spacing 0.2em + ตัวพิมพ์ใหญ่แทน

## 5 · งบประมาณ Motion — ห้ามเกิน 4 อย่างต่อหน้า

เลือกมาแค่ 4 จากรายการนี้ ที่เหลือห้ามใส่

- Text reveal ตอนโหลดหน้า (บรรทัดเลื่อนขึ้นจากใต้เส้น)
- Scroll reveal แบบ fade + เลื่อนขึ้น 24px
- Number counter ตอนเข้าจอ
- Scroll-linked diagram (แยกชั้น / เปลี่ยนสถานะตามการเลื่อน)
- Drag comparison
- Magnetic button
- Filter transition ตอนกรองรายการ

**ห้ามใช้เด็ดขาด** — parallax หลายชั้น, tilt ตามเมาส์, mouse-follow cursor, bounce, ตัวอักษรวิ่งทีละตัว, marquee เร็ว

ทุกอย่างต้องเคารพ `prefers-reduced-motion: reduce`

## 6 · Signature Element — หนึ่งเดียวต่อเว็บ

ทั้งเว็บมีของที่ "ว้าว" ได้แค่ชิ้นเดียว ที่เหลือต้องเงียบและเรียบร้อย
**Signature ของ Finnix คือ ภาพตัดขวางชั้นฟิล์ม** — เพราะมันคือสิ่งที่มีเฉพาะแบรนด์ฟิล์ม และเป็นสิ่งที่คู่แข่งทุกรายทำได้แย่

ระดับของ signature ให้เลือกตามงบ (ดูข้อ 7)
- ระดับพื้นฐาน — SVG แยกชั้นตาม scroll
- ระดับที่ควรเป็น — WebGL/Spline 3D หมุนได้ เห็นแสงตกกระทบเนื้อฟิล์ม ซูมเข้าไปเห็นอนุภาคเซรามิก

หากหน้าใดไม่มี signature ให้ปล่อยว่าง อย่าไปสร้างของว้าวชิ้นที่สอง

## 7 · เลือกโหมดตามงบภาพ

ต้องระบุโหมดทุกครั้งก่อนเริ่มงาน

### MODE A — มีงบถ่ายภาพ
ออกแบบโดยให้ภาพเป็นพระเอก typography ถอยมาเป็นตัวประกอบ hero เป็นภาพเต็มจอ คำน้อยที่สุด

**Shot list ขั้นต่ำที่ต้องได้**
- Hero — รถระยะใกล้ ตอนเย็นแสงเฉียง เห็นเนื้อฟิล์มบนกระจกข้าง แนวนอน ≥ 4000px
- ภายในรถ มุมเดียวกันทุกความเข้ม (ขาตั้งล็อกตำแหน่ง ห้ามขยับ) สำหรับตัวเลื่อนเลือกความเข้ม
- ก่อน/หลัง คู่ภาพจากมุมเดียวกัน สภาพแสงเดียวกัน
- มาโครเนื้อฟิล์ม ระยะใกล้มากจนเห็นผิวสัมผัส
- ช่างกำลังติดตั้ง — มือ ใบมีด น้ำ ฟองอากาศ (ภาพสร้างความน่าเชื่อถือสูงสุด)
- ผลงานจริง 20–30 คัน คละประเภทรถ ครอปเป็น 4:3 และ 4:5

### MODE B — ไม่มีงบภาพ
ห้ามใช้ภาพ stock เด็ดขาด แทนที่ด้วย
- Typography เป็นตัวนำ ใช้ขนาดใหญ่และช่องว่างสร้างน้ำหนัก
- 3D / WebGL สำหรับ signature แทนภาพถ่าย
- Data visualization ที่ทำจากค่าจริง (กราฟการลดความร้อน, แถบ VLT)
- ภาพจำลองที่สร้างด้วย CSS/SVG แต่ต้อง**ระบุชัดว่าเป็นภาพจำลอง** ห้ามทำให้เข้าใจผิดว่าเป็นภาพถ่ายจริง

## 8 · โครงสร้างเว็บ

```
/                     หน้าแรก
/about                เกี่ยวกับเรา — ทำไมถึงก่อตั้ง
/technology           เทคโนโลยี — signature อยู่ที่นี่
/products             ผลิตภัณฑ์ + ตารางเปรียบเทียบ
/products/[series]    รายละเอียดซีรีส์ (template เดียวใช้ 3 ครั้ง)
/warranty             การรับประกัน + ลงทะเบียน
/gallery              ผลงาน
/news                 ข่าวสาร & โปรโมชัน
/faq                  คำถามที่พบบ่อย
/contact              ติดต่อ — แยกลูกค้าทั่วไป / ธุรกิจ
```

**เมนู** จัดเป็น 3 แกน — Brand (เกี่ยวกับเรา, เทคโนโลยี, ผลงาน) · Product (ผลิตภัณฑ์) · Support (รับประกัน, ข่าวสาร, FAQ, ติดต่อ)
ทุกหน้าต้องเข้าถึงได้ภายใน 2 คลิกจากหน้าแรก

## 9 · ข้อกำหนดทางเทคนิค

- ไฟล์เดียวจบต่อหนึ่งหน้า HTML + CSS + JS อยู่ในไฟล์เดียวกัน (สำหรับขั้นตรวจแบบ) เว้นแต่สั่งเป็นอย่างอื่น
- Mobile first · จุดตัด 620 / 900 / 1080 px
- ทุกภาพต้องมี `alt` ที่บรรยายเนื้อหาจริง ไม่ใช่ชื่อไฟล์
- ลำดับหัวข้อ h1 → h6 ห้ามข้ามระดับ · หนึ่ง h1 ต่อหนึ่งหน้า
- `:focus-visible` ต้องเห็นชัดทุกองค์ประกอบที่กดได้
- ความต่างสีตัวหนังสือ ≥ 4.5:1 · ปุ่มสูงอย่างน้อย 44px
- Zero layout shift — กำหนดขนาดภาพและ `aspect-ratio` ล่วงหน้าเสมอ
- Lazy load ทุกภาพที่อยู่ใต้ first fold · แผนที่โหลดเมื่อคลิกเท่านั้น
- เป้า Lighthouse ≥ 95 ทั้งสี่หมวด **ถ้า motion ที่ขอทำให้ไม่ถึง ให้ตัด motion ไม่ใช่ตัดเป้า**

## 10 · กติกาเรื่องข้อมูลที่ยังไม่มี

ทุกค่าที่ยังไม่ได้รับจากลูกค้า ให้เขียนในรูปแบบ `{{ชื่อตัวแปร}}` เช่น `{{TSER_CM}}` `{{WARRANTY_YEARS}}` `{{SERVICE_CENTERS}}`

ท้ายงานทุกครั้ง ต้องแนบ **รายการตัวแปรที่ต้องขอ** พร้อมระบุว่าแต่ละตัวเอาไปใช้ที่ไหน

ห้ามใส่ค่าสมมติลงในไฟล์ที่จะขึ้นจริง หากทำตัวอย่างเพื่อดูดีไซน์ ต้องแจ้งชัดในคำอธิบายว่าเป็นค่าสมมติทั้งหมด

## 11 · เกณฑ์ตรวจรับ — ตอบให้ครบก่อนส่งงาน

ก่อนส่ง ให้ตรวจตัวเองแล้วรายงานผลทีละข้อ

1. ถ้าลบโลโก้ออก ยังบอกได้ไหมว่านี่คือ Finnix ไม่ใช่แบรนด์ฟิล์มอื่น
2. Signature element คืออะไร และมีชิ้นเดียวจริงไหม
3. นับ motion ในหน้านี้ได้กี่อย่าง เกิน 4 หรือไม่
4. แดงปรากฏกี่จุดต่อหนึ่งหน้าจอ
5. ทุกระยะหารด้วย 8 ลงตัวหรือไม่
6. มีค่าตัวเลขที่แต่งขึ้นเองหลงเหลืออยู่ไหม
7. เปิดที่ 375px แล้วยังอ่านง่ายและกดง่ายไหม
8. ถ้าเอา prompt นี้ไปทำเว็บสินค้าประเภทอื่น ผลลัพธ์จะเหมือนกันไหม — ถ้าเหมือน แปลว่ายังไม่เฉพาะกับ Finnix พอ
