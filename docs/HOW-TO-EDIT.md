# คู่มือแก้ไขเว็บ FINNIX FILM

สำหรับคนที่จะมาแก้เว็บต่อ — งานที่ทำบ่อยทำตามหัวข้อข้างล่างได้เลย ไม่ต้องอ่านโค้ดทั้งหมด
รายละเอียดเชิงเทคนิคอยู่ที่ `CLAUDE.md` · ประวัติการแก้อยู่ที่ `docs/CHANGELOG.md`

---

## กฎ 3 ข้อที่ต้องรู้ก่อนแก้อะไร

1. **ข้อมูลแก้ที่ `data/` · ค่าตั้งเว็บแก้ที่ `tools/build.py` แล้วรันคำสั่งนี้ทุกครั้ง**
   ```
   python tools/build.py
   ```
2. **ห้ามแก้ไฟล์ / บริเวณที่สร้างอัตโนมัติ** — จะถูกเขียนทับรอบหน้า
   - `content.js`
   - `films/titanium.html` `films/ceramic.html` `films/crystalize.html` `films/extra-clear.html` `films/uv-guard.html` (หน้ารุ่นทั้ง 5)
   - ทุกอย่างระหว่าง `<!-- @ชื่อ -->` กับ `<!-- @end ชื่อ -->` ในหน้า HTML
3. **เปิดดูผ่าน server เท่านั้น** — ดับเบิลคลิกเปิดไฟล์ตรง ๆ หน้าจะพัง (ลิงก์เป็นแบบ `/films.html`)
   ```
   python -m http.server 8000
   ```
   แล้วเปิด http://localhost:8000/

## งานที่ทำบ่อย

### เปลี่ยนเบอร์โทร · ใส่ LINE / Facebook / ที่อยู่บริษัท
แก้ `SITE` บนสุดของ `tools/build.py` แล้วรัน build
```python
'hotline': '0635978497',            # ตัวเลขล้วน
'hotline_display': '06-3597-8497',  # ที่แสดงบนหน้า
'line_url': 'https://lin.ee/xxxx',  # ใส่แล้วไอคอน LINE ท้ายเว็บกดได้เอง
'facebook_url': 'https://facebook.com/...',  # ใส่แล้วไอคอน Facebook ท้ายเว็บกดได้เอง
'address': 'เลขที่ ... ',            # None = ยังไม่มี (หน้าเว็บขึ้น {{COMPANY_ADDRESS}})
```
ค่าทั้งหมดไปขึ้นที่ footer ทุกหน้า · กล่องสำนักงานใหญ่ที่ `/dealers.html`

### แก้ชื่อเมนู / เพิ่มเมนู / ลิงก์ท้ายเว็บ
แก้ `NAV` (เมนูบน) หรือ `HOME_FOOT` (ลิงก์ท้ายเว็บ) ใน `tools/build.py` แล้วรัน build
เมนูบนมีที่ว่างจำกัด — ชื่อยาวขึ้นต้องเปิดดูที่จอกว้าง 1060–1440 ว่าไม่ชนกัน (จอ ≤1050 เป็นเมนูพับ ☰ อยู่แล้ว)

### แก้แถบ "ตอนต่อไป" ท้ายหน้า
แถบสีเข้มท้ายทุกหน้า (ยกเว้นหน้าแรก) ที่ชวนไปหน้าถัดไป — แก้ที่ `NEXT` ใน `tools/build.py` แล้วรัน build
แต่ละบรรทัดคือ หน้านี้ → (หน้าปลายทาง, ข้อความชวน) · บรรทัด `'series'` ใช้กับหน้ารุ่นทั้ง 5 หน้า
หน้าปลายทางต้องมีชื่ออยู่ใน `CHAPTERS` (ชื่ออังกฤษ, ชื่อไทย ที่ขึ้นบนป้ายเล็กของแถบ)

### แก้ค่าสเปก · ราคา · ชื่อซีรีส์
แก้ `data/films.json` แล้วรัน build — ทุกหน้าที่แสดงค่านั้นเปลี่ยนตามเอง (การ์ด · หน้ารุ่น · ตารางเทียบ · เครื่องคำนวณราคา)
**ห้ามใส่ตัวเลขที่ไม่มีเอกสารรองรับ** — ค่าที่ไม่รู้ใส่ `null`

### เพิ่ม / แก้ร้านตัวแทน
แก้ `data/dealers.json` แล้วรัน build — หนึ่งร้านหน้าตาแบบนี้
```json
{
  "id": "fnx-bkk-003",
  "name": "ชื่อร้าน",
  "address": "ที่อยู่เต็ม",
  "province": "กรุงเทพมหานคร",
  "phone": "021234567",
  "lat": 13.75, "lng": 100.50,
  "hours": "จ-ส 09:00-18:00",
  "placeholder": false
}
```
`lat` / `lng` ใช้ทำปุ่ม "ดูบนแผนที่" กับ "เส้นทาง" — หาได้จาก Google Maps (คลิกขวาที่ร้าน → ตัวเลขบนสุด)
**ตอนนี้ทั้ง 9 รายเป็นข้อมูลสมมติ** — ได้รายชื่อจริงแล้วให้ลบของเดิมทั้งหมด และเอาป้าย "ตัวอย่างการแสดงผล" ออกจาก `dealers.html`

### เพิ่มผลงานที่ติดตั้ง
แก้ `data/gallery.json` แล้วรัน build
```json
{ "car": "Toyota Camry", "series": "TITANIUM",
  "fit": [ { "position": "บานหน้า", "code": "SY40" }, { "position": "บานข้าง", "code": "SY20" } ] }
```
`series` ต้องสะกดตรงกับชื่อซีรีส์ (TITANIUM · CERAMIC · CRYSTALIZE · EXTRA CLEAR · UV GUARD) ไม่งั้นปุ่มกรองจะหาไม่เจอ
**ตอนนี้ 20 คันเป็นตัวอย่าง** — ได้ผลงานจริงแล้วเอากล่อง "ตัวอย่างการแสดงผล" (`works-notice demo-tag`) ออกจาก `works.html` · ช่องภาพบนการ์ดยังเป็นกรอบ "รอภาพผลงานจริง" (สร้างใน `gen_gallery` ของ `build.py`) — การใส่ภาพจริงต้องเพิ่มช่องภาพใน `gallery.json` ก่อน

### เปลี่ยนภาพชั่วคราวเป็นภาพจริง
ทุกช่องที่ยังเป็นภาพชั่วคราวมีป้าย "ภาพชั่วคราว" และ `data-temp` ในโค้ด — ค้นหาด้วย
```
grep -rn data-temp --include=*.html .
```
1. วางไฟล์ภาพจริงใน `assets/` (ย่อให้กว้างไม่เกิน ~1600px ก่อน)
2. แก้ `src="..."` กับ `alt="..."` (คำบรรยายภาพสำหรับคนตาบอด) ให้เป็นภาพใหม่
3. ลบ `data-temp` และบรรทัด `<span class="temp-tag">ภาพชั่วคราว</span>` ของภาพนั้น

**ภาพการ์ดซีรีส์ที่ `/films.html`** ไม่ได้อยู่ใน HTML — แก้ที่ `SERIES_PHOTO` ใน `tools/build.py` (ภาพ + ตำแหน่ง) แล้วรัน build

### ยืนยันการแนะนำซีรีส์ตามความต้องการ
ตอนนี้ระบบแนะนำ กันร้อน → TITANIUM · มองชัด → CRYSTALIZE · เป็นส่วนตัว → CERAMIC · สมดุล → UV GUARD (คำนวณจากตัวเลข ยังไม่ได้รับการยืนยัน)
บริษัทยืนยันแล้ว → เปลี่ยน `NEED_MAPPING_CONFIRMED = True` ใน `tools/build.py` · ถ้าบริษัทอยากให้แนะนำซีรีส์อื่น แก้ตัวแปร `need_rank` ในไฟล์เดียวกัน

### เพิ่มหน้าใหม่
1. คัดลอก `experience.html` เป็นไฟล์ใหม่ที่ root เช่น `promo.html` (ที่อยู่เว็บจะเป็น `/promo.html`)
2. แก้ `<title>` `<meta name="description">` และเนื้อหาใน `<main>` — **อย่าลบบรรทัด `<!-- @assets -->` `<!-- @header -->` `<!-- @footer -->`**
3. ถ้าต้องการให้อยู่ในเมนู เพิ่มใน `NAV` / `HOME_FOOT` ของ `tools/build.py` — ลิงก์เขียนแบบ `/promo.html`
4. เพิ่มหน้าใหม่ลงใน `NEXT` ของ `tools/build.py` (หน้านี้จะชวนไปหน้าไหนต่อ) — ไม่งั้น build จะเตือนเพราะไฟล์ที่คัดลอกมามีเครื่องหมาย `<!-- @next -->` · ถ้าไม่อยากมีแถบนี้ ลบบรรทัดเครื่องหมายนั้นทิ้ง
5. รัน build — สคริปต์จะเติม header/footer และแถบ "ตอนต่อไป" ให้เอง

### แก้สี · ฟอนต์ · ขนาดตัวอักษรทั้งเว็บ
แก้ `:root` บนสุดของ `style.css` — `--red` (แดงแบรนด์) · `--red-ink` (แดงของตัวหนังสือเล็ก ต้องเข้มพอให้อ่านง่าย) · `--ink` (ตัวหนังสือ) · `--paper` (พื้น)

## เขียน CSS / ข้อความไทยให้ไม่พัง

- **คำไทยถูกตัดกลางคำ** (เช่น "ดูรา / คา") — ครอบคำนั้นด้วย `<span class="nb">ดูราคา</span>`
- **ตัวหนังสือไทยห้ามเล็กกว่า 12px**
- **ตัวหนังสือสีแดงขนาดเล็ก** ใช้ `var(--red-ink)` ไม่ใช่ `var(--red)` (แดงสว่างอ่านยากบนพื้นขาว)
- ของใหม่ใส่ `merge.css` ในหมวดของหน้านั้น (ดูสารบัญหัวไฟล์) · เบรกพอยต์ใช้ 1250 / 1050 / 760 ให้ตรงกับของเดิม
- ใส่ภาพในโลโก้หรือการ์ด ต้องใส่ `height:auto` และ `object-fit:contain` เพราะ `style.css` ตั้งภาพทุกภาพเป็น `height:100%` + `cover`
