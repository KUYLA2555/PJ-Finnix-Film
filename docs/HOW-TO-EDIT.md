# คู่มือแก้ไขเว็บ FINNIX FILM

สำหรับคนที่จะมาแก้เว็บต่อ — งานที่ทำบ่อยทำตามหัวข้อข้างล่างได้เลย ไม่ต้องอ่านโค้ดทั้งหมด
รายละเอียดเชิงเทคนิคอยู่ที่ `CLAUDE.md` · ประวัติการแก้อยู่ที่ `docs/CHANGELOG.md`

---

## กฎ 3 ข้อที่ต้องรู้ก่อนแก้อะไร

1. **ข้อมูลแก้ที่ `data/` · ค่าตั้งเว็บแก้ที่ `tools/build.py` แล้วรันคำสั่งนี้ทุกครั้ง**
   ```
   python tools/build.py
   ```
2. **ห้ามแก้ไฟล์ / บริเวณที่สร้างอัตโนมัติ** — จะถูกเขียนทับรอบหน้า
   - `content.js`
   - `films/titanium.html` `films/ceramic.html` `films/ceramic-plus.html` `films/crystalize.html` `films/extra-clear.html` `films/uv-guard.html` (หน้ารุ่นทั้ง 6)
   - ทุกอย่างระหว่าง `<!-- @ชื่อ -->` กับ `<!-- @end ชื่อ -->` ในหน้า HTML
3. **เปิดดูผ่าน server เท่านั้น** — ดับเบิลคลิกเปิดไฟล์ตรง ๆ ใช้งานไม่ได้
   ```
   python -m http.server 8000
   ```
   แล้วเปิด http://localhost:8000/
   - ลิงก์ในหน้าเขียนแบบ `/films.html` ได้ตามเดิม — build แปลงเป็นแบบที่ใช้บนเว็บจริงได้ (`films.html` · `../films.html`) ให้เอง (v8.6)
   - **แก้ HTML แล้วต้องรัน build ก่อน push เสมอ** — ถ้าลิงก์ที่ขึ้นต้นด้วย `/` หลุดขึ้นไป บนเว็บจริงจะเจอหน้า 404 เพราะเว็บอยู่ใต้ `/PJ-Finnix-Film/`

## งานที่ทำบ่อย

### เปลี่ยนเบอร์โทร · ใส่ LINE / Facebook / ที่อยู่บริษัท
แก้ `SITE` บนสุดของ `tools/build.py` แล้วรัน build
```python
'hotline': '0635978497',            # ตัวเลขล้วน
'hotline_display': '06-3597-8497',  # ที่แสดงบนหน้า
'line_url': 'https://lin.ee/xxxx',  # ใส่แล้วไอคอน LINE ท้ายเว็บกดได้เอง
'facebook_url': 'https://facebook.com/...',  # ใส่แล้วไอคอน Facebook ท้ายเว็บกดได้เอง
'address': 'เลขที่ ... ',            # None = ยังไม่มี (หน้าเว็บขึ้น "รอข้อมูล")
```
ค่าทั้งหมดไปขึ้นที่ footer ทุกหน้า · กล่องสำนักงานใหญ่ที่ `/dealers.html`
ช่องที่ยังขึ้น "รอข้อมูล" บนเว็บ — ค้นได้ด้วย `grep -rn data-var` (ชื่อตัวแปรอยู่ใน `data-var="..."` · v8.8) · ช่องในหน้าที่เขียนมือ (หมายเหตุใต้การ์ด `/films.html` · กล่องแจ้งที่ `/dealers.html` `/works.html`) ได้ข้อมูลแล้วให้แก้ข้อความในหน้านั้นเอง

### แก้ชื่อเมนู / เพิ่มเมนู / ลิงก์ท้ายเว็บ
แก้ `NAV` (เมนูบน) หรือ `HOME_FOOT` (ลิงก์ท้ายเว็บ) ใน `tools/build.py` แล้วรัน build
เมนูบนมีที่ว่างจำกัด — ชื่อยาวขึ้นต้องเปิดดูที่จอกว้าง 1060–1440 ว่าไม่ชนกัน (จอ ≤1050 เป็นเมนูพับ ☰ อยู่แล้ว)

### แก้แถบ "ตอนต่อไป" ท้ายหน้า
แถบสีเข้มท้ายทุกหน้า (ยกเว้นหน้าแรก) ที่ชวนไปหน้าถัดไป — แก้ที่ `NEXT` ใน `tools/build.py` แล้วรัน build
แต่ละบรรทัดคือ หน้านี้ → (หน้าปลายทาง, ข้อความชวน) · บรรทัด `'series'` ใช้กับหน้ารุ่นทุกหน้า
หน้าปลายทางต้องมีชื่ออยู่ใน `CHAPTERS` (ชื่ออังกฤษ, ชื่อไทย ที่ขึ้นบนป้ายเล็กของแถบ)
ข้อความชวนเป็น HTML (v8.7) — คำที่ไม่อยากให้ถูกตัดขึ้นบรรทัดใหม่ครอบด้วย `<span class="nb">…</span>` · ถ้าจะพิมพ์ `&` `<` `>` ให้เขียนเป็น `&amp;` `&lt;` `&gt;`

### แก้ค่าสเปก · ราคา · ชื่อซีรีส์
แก้ `data/films.json` แล้วรัน build — ทุกหน้าที่แสดงค่านั้นเปลี่ยนตามเอง (การ์ด · หน้ารุ่น · ตารางเทียบ · เครื่องคำนวณราคา)
**ห้ามใส่ตัวเลขที่ไม่มีเอกสารรองรับ** — ค่าที่ไม่รู้ใส่ `null`

### ได้ข้อมูล CERAMIC PLUS แล้ว (v9.1)
ซีรีส์ที่ 6 ยังไม่มีโบรชัวร์ ทุกช่องขึ้น "รอข้อมูล" — ได้เอกสารแล้วทำตามนี้ แล้วรัน build ครั้งเดียว
1. **ตัวเลข** — `data/films.json` ซีรีส์ `ceramic-plus` แทน `null` ในแต่ละรหัส (`heatReject` `vlt` `darkness` `reflect` `uv` `ir`) · ถ้ารหัสจริงไม่ใช่ CM35/CM15/CM05 แก้ `code` ด้วย
2. **ข้อความ** — `tagline` (หัวรองบนภาพใหญ่) · `claim` · `tech` (`ceramic` ถ้าเป็นเซรามิก) · `metalFree` (`true`/`false`) · `warrantyYears` (ลบบรรทัดนี้ทิ้งถ้าเท่ากับซีรีส์อื่น 7 ปี) · `name.th` ถ้าชื่อไทยไม่ตรง
3. **ราคา** — ใส่ `price` รูปแบบเดียวกับ CERAMIC (6 ประเภทรถ × บานหน้า/รอบคัน)
4. ~~**โลโก้**~~ **มีแล้ว (v9.3 · v9.5 ประกอบใหม่ให้คม)** — `assets/series/logo-ceramic-plus.png` 892x268 เป็นงานประกอบชั่วคราวจากโลโก้ CERAMIC (ไฟล์ที่ผู้สั่งงานส่งมาเล็ก 350x104 ขยายแล้วแตก) · ได้ไฟล์จริงความละเอียดสูงจากบริษัท (กว้าง 800px ขึ้นไป พื้นใส) วางทับชื่อเดิม แล้วรัน `python tools/logo_white.py` ก่อน build
5. **ปกโบรชัวร์** — ย่อปกเป็นกว้าง 880px วางที่ `assets/Brochure/cover-CMP.jpg` (ชื่ออะไรก็ได้) แล้วเพิ่ม `'ceramic-plus': 'cover-CMP.jpg'` ใน `COVER` ของ `tools/build.py`
มีตัวเลขครบแล้ว CERAMIC PLUS จะเข้าไปอยู่ในระบบแนะนำตามความต้องการและการ์ด "ทางเลือกอื่น" ท้ายหน้ารุ่นเอง

### สีฟิล์มบนปุ่มเลือกรหัส (ภาพมองผ่านกระจก · v9.1)
ปุ่มเลือกรหัสบนหน้ารุ่นเป็นภาพเมืองจากในรถที่ทับสีฟิล์มเฉพาะช่องกระจก — สีมาจาก `tint` ของแต่ละรหัสใน `data/films.json` (เช่น `"tint": "#c7b5ad"`) แล้วรัน build
- `tint` วัดจากภาพถ่ายแผ่นตัวอย่างจริง (ต้นฉบับอยู่ในคลัง `ไฟล์ต้นฉบับ\filmcolor\`) — **ไม่ใช่ค่าสเปก** ห้ามเอาไปเขียนเป็นตัวเลขบนเว็บ
- สีอ่อน = ใสกว่า · สีเข้ม = มืดกว่า · สีขาว `#ffffff` = ไม่ทับสีเลย · ปรับทีละรหัสได้ถ้าเทียบของจริงแล้วไม่ตรง
- ช่องกระจกกำหนดด้วย `assets/glass-window.svg` (ขนาดเท่า `glass.jpg`) — ถ้าเปลี่ยนภาพ `glass.jpg` ต้องวาดรูปช่องกระจกในไฟล์นี้ใหม่ด้วย

### เพิ่ม / แก้ร้านตัวแทน
แก้ `data/dealers.json` แล้วรัน build — หนึ่งร้านหน้าตาแบบนี้
```json
{
  "id": "fnx-bkk-003",
  "name": "ชื่อร้าน",
  "address": "ที่อยู่เต็ม",
  "province": "กรุงเทพมหานคร",
  "phone": "021234567",
  "lat": 13.75, "lng": 100.50,
  "hours": "จ-ส 09:00-18:00",
  "placeholder": false

```
`lat` / `lng` ใช้ทำปุ่ม "ดูบนแผนที่" กับ "เส้นทาง" — หาได้จาก Google Maps (คลิกขวาที่ร้าน → ตัวเลขบนสุด)
**ตอนนี้ทั้ง 9 รายเป็นข้อมูลสมมติ** — ได้รายชื่อจริงแล้วให้ลบของเดิมทั้งหมด และเอาป้าย "ตัวอย่างการแสดงผล" ออกจาก `dealers.html`

### เพิ่มผลงานที่ติดตั้ง
แก้ `data/gallery.json` แล้วรัน build
```json
{ "car": "Toyota Camry", "series": "TITANIUM",
  "fit": [ { "position": "บานหน้า", "code": "SY40" }, { "position": "บานข้าง", "code": "SY20" } ] }
```
`series` ต้องสะกดตรงกับชื่อซีรีส์ (TITANIUM · CERAMIC · CRYSTALIZE · EXTRA CLEAR · UV GUARD) ไม่งั้นปุ่มกรองจะหาไม่เจอ
**ตอนนี้ 20 คันเป็นตัวอย่าง** — ได้ผลงานจริงแล้วเอากล่อง "ตัวอย่างการแสดงผล" (`works-notice demo-tag`) ออกจาก `works.html` · ช่องภาพบนการ์ดยังเป็นกรอบ "รอภาพผลงานจริง" (สร้างใน `gen_gallery` ของ `build.py`) — การใส่ภาพจริงต้องเพิ่มช่องภาพใน `gallery.json` ก่อน

### เปลี่ยนภาพชั่วคราวเป็นภาพจริง
ทุกช่องที่ยังเป็นภาพชั่วคราวมีป้าย "ภาพชั่วคราว" และ `data-temp` ในโค้ด — ค้นหาด้วย
```
grep -rn data-temp --include=*.html .
```
1. วางไฟล์ภาพจริงใน `assets/` (ย่อให้กว้างไม่เกิน ~1600px ก่อน)
2. แก้ `src="..."` กับ `alt="..."` (คำบรรยายภาพสำหรับคนตาบอด) ให้เป็นภาพใหม่
3. ลบ `data-temp` และบรรทัด `<span class="temp-tag">ภาพชั่วคราว</span>` ของภาพนั้น

**ภาพการ์ดซีรีส์ที่ `/films.html`** ไม่ได้อยู่ใน HTML — ภาพอยู่ที่ `assets/series/card-<id>.jpg` (v9.2) · เปลี่ยนภาพ = ย่อภาพใหม่ให้กว้างราว 880px แล้ววางทับชื่อเดิม (เช่น `card-titanium.jpg`) แล้วรัน build · ตำแหน่งภาพในกรอบแก้ที่ `SERIES_CARD` ใน `tools/build.py` (`center 75%` = เลื่อนกรอบลงให้เห็นตัวรถ) · ย่อด้วย ffmpeg: `ffmpeg -i "ต้นฉบับ.png" -vf scale=880:-2 -q:v 4 assets/series/card-titanium.jpg` · ต้นฉบับเก็บในคลัง ไม่วางใน `assets/`
- เอาเมาส์ชี้ภาพแล้วกระจกดำ (ฟิล์มเข้ม) เลื่อนขึ้นจากขอบล่างพร้อมโลโก้ซีรีส์ (v9.4) — โลโก้บนกระจกเป็นฉบับพื้นมืด `assets/series/logo-<id>-white.png` (ส่วนดำเป็นขาว สีแบรนด์คงเดิม) สร้างจาก `logo-<id>.png` ของหน้ารุ่น · **เปลี่ยนหรือเพิ่มโลโก้ซีรีส์ ให้รัน `python tools/logo_white.py` ก่อน แล้วค่อยรัน build** (ต้องมี ffmpeg) · ซีรีส์ที่ไม่มีไฟล์โลโก้จะขึ้นชื่อเป็นตัวหนังสือสีขาวแทน
- ภาพใหญ่หัวหน้ารุ่นและการ์ด "ทางเลือกอื่น" ในหน้ารุ่นใช้อีกชุด — แก้ที่ `SERIES_PHOTO`

### เปลี่ยนวิดีโอปกหน้าแรก (v8.9 · v9.0)
ปกหน้าแรกเป็นวิดีโอ เล่นเอง วนซ้ำ ไม่มีเสียง — `assets/video/hero.mp4` (จอใหญ่) · `hero-720.mp4` (มือถือ) · ภาพก่อนวิดีโอเริ่ม `hero-poster.jpg` · อยู่ใน `index.html` ส่วน `class="hero"`
1. **บีบไฟล์ก่อนเสมอ และตัดเสียงออก** — ไฟล์จากกล้อง/โปรแกรมตัดต่อมักใหญ่หลายสิบ MB (ผู้เข้าชมทุกคนต้องโหลด · push ขึ้น GitHub ไม่ผ่าน) ใช้ ffmpeg (มีในเครื่องแล้ว) ทำ 3 ไฟล์:
```
ffmpeg -i "ต้นฉบับ.mp4" -an -vf scale=-2:1080 -c:v libx264 -preset slow -crf 26 -pix_fmt yuv420p -movflags +faststart assets/video/hero.mp4
ffmpeg -i "ต้นฉบับ.mp4" -an -vf scale=-2:720 -c:v libx264 -preset slow -crf 27 -pix_fmt yuv420p -movflags +faststart assets/video/hero-720.mp4
ffmpeg -ss 0 -i assets/video/hero.mp4 -frames:v 1 -vf scale=1600:-2 -q:v 4 assets/video/hero-poster.jpg
```
   (`-an` = ไม่เอาเสียง · `scale=-2:1080` = ย่อเหลือ 1080p เมื่อต้นฉบับใหญ่กว่า (v9.0 ต้นฉบับ 2560x1440) · `-crf` น้อยลง = ชัดขึ้นแต่ไฟล์ใหญ่ขึ้น · คลิป 40 วิได้ราว 9–10 MB / 4–5 MB · ภาพปกใช้เฟรมแรกจะได้ไม่กระตุกตอนวิดีโอเริ่ม)
2. เก็บต้นฉบับไว้ที่คลัง `top secret\Finnix\ไฟล์ต้นฉบับ\ต้นฉบับรูปบนเว็บ\` — **อย่าวางต้นฉบับใหญ่ไว้ใน `assets/`**
3. ชื่อไฟล์ใหม่ห้ามมีช่องว่าง · ถ้าเปลี่ยนชื่อ แก้ทั้ง `<source src>` สองบรรทัด และ `poster=` (`poster` ต้องเขียนแบบ `assets/...` ไม่มี `/` นำหน้า)
4. คลิปใหม่ต้องเปิดดูทั้งจอใหญ่และมือถือว่าข้อความปก (A CLEARER TOMORROW) ยังอ่านออกทุกฉาก — ความเข้มม่านหลังข้อความแก้ที่ `.hero-wash` ใน `merge.css` (หมวด 5 จอใหญ่ · หมวด 15 มือถือ)

### ใส่ / เปลี่ยนรถ 3D หน้าแรกส่วน 04 (v9.5)
ส่วน 04 "TRY FINNIX" ทำไว้ให้แสดงรถ 3D ที่ลากหมุนดูรอบคันได้ พร้อมปุ่ม Clear · 40 · 60 · 80 เปลี่ยนความเข้มของกระจก — **ยังไม่มีไฟล์โมเดล หน้าเว็บจึงขึ้นภาพเมืองแบบเดิมอยู่** · ได้ไฟล์แล้วทำตามนี้:
1. **ไฟล์ต้องเป็น `.glb` แบบไม่บีบอัด** (Sketchfab: Download 3D Model → glTF → เลือกไฟล์ **GLB**) · **ห้ามแบบบีบอัด Draco / KTX2** — เว็บบล็อกตัวถอดรหัสจากภายนอก จะขึ้น "โหลดรถ 3D ไม่ได้" · ขนาดควรไม่เกิน ~10 MB (ผู้เข้าชมโหลดเมื่อกดปุ่มเท่านั้น · push เกิน ~2 MB จากเครื่องนี้มักไม่ผ่าน ดูค้างข้อ 37)
2. ตั้งชื่อ `car.glb` วางที่ `assets/3d/` (สร้างโฟลเดอร์เอง)
3. **ใส่เครดิต** ที่ `CAR_3D['credit']` ใน `tools/build.py` ตามสัญญาอนุญาตของโมเดล (ไม่ใส่ = build ไม่ยอมผ่าน) — โมเดล CC BY ต้องมีชื่อโมเดล ชื่อผู้สร้าง ลิงก์ และชื่อสัญญา เช่น
   `'credit': 'โมเดล 3D "ชื่อโมเดล" โดย <a href="ลิงก์ผู้สร้าง">ชื่อผู้สร้าง</a> · <a href="https://creativecommons.org/licenses/by/4.0/">CC BY 4.0</a>',`
   · ห้ามเขียนให้เข้าใจว่าเว็บเกี่ยวข้องกับยี่ห้อรถ (สัญญาครอบคลุมตัวโมเดล ไม่ใช่เครื่องหมายการค้าของรถ)
4. สร้างภาพนิ่ง 4 ระดับ (ต้องมี Chrome ในเครื่อง · ใช้เวลาราว 1 นาที)
   ```
   python tools/car_posters.py
   ```
   ดูบรรทัด "← วัสดุกระจก" — ถ้าขึ้นว่าไม่เจอ แปลว่าโมเดลไม่มีวัสดุชื่อ glass / window และไม่มีวัสดุโปร่ง ปุ่มความเข้มจะไม่เปลี่ยนอะไร → หาโมเดลอื่น · เปิดดู `assets/3d/car-0.jpg` ถึง `car-3.jpg` ว่ากระจกเข้มขึ้นตามลำดับและรถอยู่กลางภาพ
5. รัน build → หน้าแรกเปลี่ยนเป็นรถ 3D เอง · เปิดหน้าแรก กด "หมุนดูรถ 3D รอบคัน" ลองลากหมุนและกดปุ่มความเข้มทุกปุ่ม ทั้งจอคอมและมือถือ
- **มุมกล้องตอนเปิด** แก้ที่ `CAR_3D['orbit']` (`มุมรอบคัน มุมก้มเงย ระยะ` เช่น `-35deg 75deg auto`) · **ความทึบกระจก** แก้ที่ `CAR_3D['glass']` เรียง Clear · 40 · 60 · 80 (`None` = กระจกเดิมของโมเดล · 0–1 ยิ่งมากยิ่งทึบ · เป็นภาพจำลอง ไม่ใช่ค่า VLT) — แก้แล้วรัน `car_posters.py` ใหม่ก่อน build ทุกครั้ง
- **เอารถ 3D ออก** = ลบโฟลเดอร์ `assets/3d/` แล้วรัน build → กลับเป็นภาพเมือง

### ยืนยันการแนะนำซีรีส์ตามความต้องการ
ตอนนี้ระบบแนะนำ กันร้อน → TITANIUM · มองชัด → CRYSTALIZE · เป็นส่วนตัว → CERAMIC · สมดุล → UV GUARD (คำนวณจากตัวเลข ยังไม่ได้รับการยืนยัน)

### แก้สี · ฟอนต์ · ขนาดตัวอักษรทั้งเว็บ
แก้ `:root` บนสุดของ `style.css` — `--red` (แดงแบรนด์) · `--red-ink` (แดงของตัวหนังสือเล็ก ต้องเข้มพอให้อ่านง่าย) · `--ink` (ตัวหนังสือ) · `--paper` (พื้น)

## เขียน CSS / ข้อความไทยให้ไม่พัง

- **คำไทยถูกตัดกลางคำ** (เช่น "ดูรา / คา") — ครอบคำนั้นด้วย `<span class="nb">ดูราคา</span>`
- **ตัวหนังสือไทยห้ามเล็กกว่า 12px**
- **ตัวหนังสือสีแดงขนาดเล็ก** ใช้ `var(--red-ink)` ไม่ใช่ `var(--red)` (แดงสว่างอ่านยากบนพื้นขาว)
- ของใหม่ใส่ `merge.css` ในหมวดของหน้านั้น (ดูสารบัญหัวไฟล์) · เบรกพอยต์ใช้ 1250 / 1050 / 760 ให้ตรงกับของเดิม
- ใส่ภาพในโลโก้หรือการ์ด ต้องใส่ `height:auto` และ `object-fit:contain` เพราะ `style.css` ตั้งภาพทุกภาพเป็น `height:100%` + `cover`
