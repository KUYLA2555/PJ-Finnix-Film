รูปสแกนโบรชัวร์ที่ **ย่อมาให้ขนาดเหมาะกับเว็บ** — ใช้ในบล็อก `#brochure` ที่ `/technology` (เพิ่มใน v4.0)

| ไฟล์ | ซีรีส์ | หน้า |
|---|---|---|
| `sy-1` … `sy-4` | TITANIUM | 4 |
| `cm-1` … `cm-4` | CERAMIC | 4 |
| `ct-1` … `ct-3` | CRYSTALIZE | 3 |
| `xt-1` … `xt-3` | EXTRA CLEAR | 3 |
| `sm-1` … `sm-3` | UV GUARD | 3 |

รวม **17 ไฟล์ 1.6 MB** · กว้าง 760px ทุกไฟล์ · JPEG คุณภาพ 0.78 · ไฟล์ละ 59–124 KB

## มาจากไหน

ย่อจาก `scans/` (ต้นฉบับ 1470–1753px กว้าง รวม **10.1 MB**) — เป็นเอกสารชุดเดียวกับ `assets/Brochure/*.pdf`
**เครื่องนี้ไม่มี Pillow** จึงย่อด้วย `canvas.drawImage` + `toDataURL('image/jpeg', 0.78)` ในเบราว์เซอร์ แล้วส่งกลับผ่านตัวรับ HTTP ชั่วคราวที่รันเฉพาะตอน build
**ถ้าต้องย่อใหม่ ให้ทำแบบเดิม** — วิธีเต็มอยู่ใน `docs/CHANGELOG.md` หัวข้อ v4.0 · **ห้าม commit รูปต้นฉบับขนาดเต็มขึ้นเว็บ**

## กฎ

- **เป็นข้อยกเว้น MODE B ที่ผู้สั่งงานสั่งเองใน v4.0** — เป็นเอกสารของแบรนด์เอง ไม่ใช่ภาพ stock ไม่ใช่ภาพที่จ้างถ่าย · **ห้ามขยายข้อยกเว้นนี้ไปหน้าอื่นโดยไม่ถาม**
- **ทุกรูปต้องมี `loading="lazy"` ห้ามถอด** — หน้าเดียวมี 17 รูป แต่ผู้ชมเห็นทีละรูปเท่านั้น ถ้าถอดจะโหลด 1.6 MB รวดเดียว
- **ทุกรูปต้องมี `alt` ที่บอกซีรีส์และเลขหน้า** ไม่ใช่ `alt=""`
- **ชื่อไฟล์ผูกกับ markup ตรง ๆ** (`<รหัสตัวเล็ก>-<เลขหน้า>.jpg`) เปลี่ยนชื่อเมื่อไหร่ต้องแก้ `technology.html` พร้อมกัน

```bash
# ลิงก์รูปทั้งหมดต้องชี้ไฟล์ที่มีจริง — รันทุกครั้งที่แตะโฟลเดอร์นี้
for f in $(grep -o 'assets/brochure-pages/[a-z0-9-]*\.jpg' technology.html | sort -u); do
  [ -f "$f" ] && echo "OK     $f" || echo "BROKEN $f"; done
```
