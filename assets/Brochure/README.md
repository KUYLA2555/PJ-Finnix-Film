## กฎที่ต้องรู้ก่อนแตะ

- **ทุกไฟล์เป็นสแกนภาพล้วน ไม่มี text layer** (`/Font` = 0 ทุกไฟล์ · ตรวจซ้ำ 28 ส.ค. 2569)
  เป็นเอกสารชุดเดียวกับ `scans/` ที่ถอดลง `data/films.json` ไปแล้วตั้งแต่ v1.4 — **ไม่มีข้อมูลใหม่แม้แต่ค่าเดียว** อย่าเปิดอ่านเพื่อหาสเปก ให้ใช้ `films.json` กับ `docs/film-data.md` แทน
- **ห้าม render หน้า PDF บนหน้าเว็บ** เพราะเป็นภาพถ่าย ผิด MODE B · ใช้เป็น**ไฟล์ให้ดาวน์โหลดอย่างเดียว**
- ลิงก์ `download` ไม่ใช่ request ภายนอก จึงไม่ขัดข้อ 9

## ใครเรียกใช้

**ไม่มีหน้าไหนในเว็บลิงก์ถึงไฟล์พวกนี้แล้วตั้งแต่ v4.0** — ผู้สั่งงานสั่งตัดลิงก์ "ดาวน์โหลดโบรชัวร์ต้นฉบับ" ออกจากบล็อก `#brochure` ทั้ง 5 ใบ

ไฟล์ยังเก็บไว้เพราะ **เป็นเอกสารอ้างอิงของตัวเลขทุกตัวใน `data/films.json`** (ชุดเดียวกับ `scans/`) ตรวจย้อนได้เหมือนเดิม
**ห้ามลบทิ้งโดยไม่ถาม** และถ้าจะเอาลิงก์ดาวน์โหลดกลับ ต้องถามก่อนเช่นกัน

**บทเรียนที่ยังใช้ได้ถ้าเอาลิงก์กลับ** — v3.7 เคยเปลี่ยนชื่อไฟล์แล้วลืมแก้ `href` ลิงก์เสียทั้ง 5 จุดโดยไม่มีอาการเตือน
ตอนนั้นข้อความ `.bro-meta` (`PDF · N หน้า · N MB`) ต้องตรงกับตารางข้างบนด้วย **เปลี่ยนไฟล์เมื่อไหร่ต้องวัดใหม่**

```bash
# ไม่ควรมีหน้าไหนลิงก์ถึงไฟล์พวกนี้แล้ว — ถ้าเจอ แปลว่ามีคนเอาลิงก์กลับมาโดยไม่ได้อัปเดต README นี้
grep -l 'assets/Brochure/' *.html || echo "ไม่มีหน้าไหนลิงก์ถึง ถูกต้องแล้ว"
```
