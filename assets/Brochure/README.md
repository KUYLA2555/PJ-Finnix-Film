## กฎที่ต้องรู้ก่อนแตะ

- **ทุกไฟล์เป็นสแกนภาพล้วน ไม่มี text layer** (`/Font` = 0 ทุกไฟล์ · ตรวจซ้ำ 28 ส.ค. 2569)
  เป็นเอกสารชุดเดียวกับ `scans/` ที่ถอดลง `data/films.json` ไปแล้วตั้งแต่ v1.4 — **ไม่มีข้อมูลใหม่แม้แต่ค่าเดียว** อย่าเปิดอ่านเพื่อหาสเปก ให้ใช้ `films.json` กับ `docs/film-data.md` แทน
- **ห้าม render หน้า PDF บนหน้าเว็บ** เพราะเป็นภาพถ่าย ผิด MODE B · ใช้เป็น**ไฟล์ให้ดาวน์โหลดอย่างเดียว**
- ลิงก์ `download` ไม่ใช่ request ภายนอก จึงไม่ขัดข้อ 9

## ใครเรียกใช้

`technology.html` บล็อก `#brochure` — ลิงก์ `.bro-dl` ใบละหนึ่งลิงก์ ครบ 5 ใบ **ไม่มีที่อื่นเรียกใช้**

**แก้ชื่อไฟล์เมื่อไหร่ ต้องแก้ `href` ใน `technology.html` พร้อมกันเสมอ** — v3.7 เคยเปลี่ยนชื่อแล้วลืมแก้ href ลิงก์เสียทั้ง 5 จุด
ข้อความ `.bro-meta` บนหน้า (`PDF · N หน้า · N MB`) ต้องตรงกับตารางข้างบน **เปลี่ยนไฟล์เมื่อไหร่ต้องวัดใหม่**

```bash
# ลิงก์ทั้ง 5 ต้องขึ้น OK ครบ — รันทุกครั้งที่แตะโฟลเดอร์นี้
for p in $(grep -o 'assets/Brochure/[A-Za-z-]*\.pdf' technology.html); do
  [ -f "$p" ] && echo "OK     $p" || echo "BROKEN $p"; done
```
